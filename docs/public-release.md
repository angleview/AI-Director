# 公开发布内容与脱敏范围

本次公开版本从本地工程当前文件生成独立快照。它不包含原开发仓库的历史，因此旧提交中的设备信息不会随发布传播。

保留：应用源码、测试、资产获取/回放脚本、完整 NCNN 模型、学习与架构文档、历史设备与性能证据。

移除：凭据与 .local、自动化内部日志及状态、个人求职资料、内网地址、设备主机名、真实用户名与工作区路径。Git 作者使用 GitHub noreply 地址。

历史 benchmark JSON 的 input/model 路径改成项目相对路径，hostname 标为 redacted；回放 metadata 路径同样改为相对路径。测量数值、配置、时间、模型和输入 SHA-256 不变。公开报告标注 metadata_redacted，不能称其文件本身与私有原始报告逐字节一致。

真实推理入口是 [部署说明](deployment.md)。原型与同步核心的实际功能边界保持原样；补充依赖和模型不意味着完成实时并发或物理闭环。
